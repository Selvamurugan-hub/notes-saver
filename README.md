# Notes App

A simple Notes App built using HTML, Bootstrap, JavaScript, and Local Storage.

## Features

* Add notes
* Delete notes
* Search notes
* Priority selection
* Dark mode toggle
* Download notes as a text file
* Clear all notes

## Technologies Used

* HTML
* CSS (Bootstrap)
* JavaScript
* Local Storage

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
